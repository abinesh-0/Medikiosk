# 3-minute judge flow

## Opening (20 sec)
“Government OPD doctors have very limited consultation time. MediKiosk moves structured history collection and prior-record organization to the point before the consultation, so the doctor receives a concise verified draft instead of starting from zero.”

## Live flow (2 min)
1. Select Tamil or English.
2. Enter patient demographics.
3. Select Normal Consultation.
4. Answer “Chest or heart-related symptom”.
5. Demonstrate voice input and adaptive questions.
6. Answer “Severe” + “breathing difficulty” to trigger a red-flag priority.
7. Open previous-history scan/upload and paste a short sample report text.
8. Show extracted diagnosis/medication/investigation information in the summary.
9. Show Cardiology routing and token.
10. Log in as the Cardiology department account with the current doctor name.
11. Open the patient, review the structured history and red flag, then verify/complete.

## Second mini-demo (30 sec)
Start a new patient → AYUSH Consultation → show questions about digestion, food, sleep/routine and other Ayurveda-oriented assessment.

## Closing
“MediKiosk does not diagnose or replace the doctor. It addresses the first-mile clinical intake bottleneck: structured history, document intelligence, safety escalation, routing and a doctor-verifiable summary before consultation.”
